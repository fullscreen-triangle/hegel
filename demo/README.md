## 🚀 Quick Start

```bash
# Install the demo package (simplified for Python 3.13)
cd demo
pip install -r requirements.txt
pip install -e .

# Run all demonstrations (PNG/JSON output only)
python run_all_demos.py

# Quick validation mode
python run_all_demos.py --quick

# CLI interface
hegel-demo run-all
hegel-demo oxygen    # Individual demonstrations
hegel-demo validate  # Quick validation only

# Individual demonstration scripts
python demos/01_oxygen_information_processing.py
```
